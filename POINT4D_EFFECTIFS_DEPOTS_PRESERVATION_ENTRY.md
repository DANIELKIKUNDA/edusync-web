# Point 4D — Effectifs & Dépôts — entrée de préservation

Le prochain port doit commencer par copie/parité, pas par redesign.

Contrats Desktop déjà certifiés à reprendre :

- périmètre unique : Toute l'école / Maternelle / Primaire / Secondaire ;
- KPI : élèves actifs, classes actives, moyenne par classe ;
- onglets : Par classe, Par section, Par filière/option, Mouvements ;
- F/G/T annuels pour inscrits, abandons, transférés et actifs ;
- mouvements filtrés/paginés sans fusion d'années ;
- registre des dépôts filtré par le même périmètre ;
- exports PDF/Excel filtrés ;
- PDF A4 paysage ;
- identité/logotype/adresse/contacts de l'école ;
- Excel `Par classe` à 14 colonnes ;
- groupes `Inscrits`, `Abandons`, `Transférés`, `Élèves actifs`, chacun avec F/G/T ;
- total général F/G/T ;
- aucun élément hors périmètre actif.

La prochaine implémentation Web devra prouver la parité de ces contrats avant toute amélioration additive.
