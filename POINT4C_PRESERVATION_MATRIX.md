# Point 4C — Matrice de préservation corrigée

| Actif Desktop certifié | Décision Web | État |
|---|---|---|
| Identité élève permanente | reprise sans recréation annuelle | PASS |
| Inscription annuelle | reprise + idempotence/audit | PASS |
| Réinscription | conserve identité et foyer | PASS contractuel |
| Foyer/famille permanent | repris | PASS |
| Responsable distinct du foyer | repris et renforcé | PASS |
| Résolution assistée du foyer | reprise sans fusion silencieuse | PASS |
| Famille nombreuse | bénéficiaire explicite conservé | PASS contractuel |
| Enfant d'agent | lien explicite conservé | PASS contractuel |
| Historique statuts | abandon/transfert/réintégration audités | PASS |
| Recherche transversale | reprise + périmètre tenant/scope | PASS |
| Annuaire filtré | année/section/classe/statut/sexe | PASS |
| PDF liste élèves | colonnes et ordre Desktop exacts, en-tête école | PASS |
| XLSX liste élèves | colonnes et ordre Desktop exacts, filtre/freeze | PASS |
| Répertoire familles PDF/XLSX | colonnes Desktop exactes | PASS |
| Vues familles éligibles | contrat conservé | À raccorder au document Web spécialisé |
| Vues bénéficiaires | contrat conservé | À raccorder au document Web spécialisé |
| Vues enfants du personnel | contrat conservé | À raccorder au document Web spécialisé |
| Logo / identité / coordonnées école | restaurés dans les documents | PASS |
| Sexe à l'inscription | obligatoire par défaut | PASS |
| Date/lieu naissance | optionnels par défaut, complétables | PASS |

## Doctrine

Aucune amélioration Web ne peut retirer, renommer ou réordonner silencieusement une donnée d'un document certifié. Toute évolution documentaire supplémentaire doit être additive ou explicitement validée par le propriétaire produit.
